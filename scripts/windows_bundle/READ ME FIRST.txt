Buzz Drill and StockFisher for Windows
======================================

Python is built in. There is nothing else to install.

Buzz Drill:   double-click "Start Buzz Drill".
StockFisher:  double-click "Start StockFisher". The first start downloads the
              QBReader questions (about 900 MB, around 10 to 20 minutes).

Keep the black window open while you use an app. Close it to quit.

If Windows asks whether to run the file, click Run. If it says
"Windows protected your PC", click More info, then Run anyway.

Each start checks for a newer version and updates itself. Your Buzz Drill
results stay in the data folder here and are never replaced.

Anki (optional): to see which answers are already in your Anki cards, open the
Anki desktop app with the AnkiConnect add-on (Tools > Add-ons > Get Add-ons,
code 2055492159, then restart Anki).

Help and the full guide: https://github.com/tygerthelyon/qbcards
