**Download `QBCards-Windows.zip` below.** Python is built in, so there is nothing else to install.

1. Right-click the ZIP and choose **Extract All**.
2. Open the **QBCards** folder and double-click **Start Buzz Drill** or **Start StockFisher**.

If Windows asks whether to run the file, click **Run** (or **More info**, then **Run anyway**). Keep the black window open while you use an app; close it to quit. StockFisher's first start downloads the QBReader questions (about 900 MB, around 10 to 20 minutes).

This file is rebuilt automatically whenever the apps change, and an installed copy updates itself each time it starts (your results are kept). Copies downloaded before 17 November 2026 don't have the updater yet: download once more and copy your old `data` folder into the new QBCards folder.
